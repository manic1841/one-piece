# 歷史財務分析 (Financial Analysis)

`/reports/analysis` 是報表的分析子頁，只讀**已產生報表**與既有 portfolio snapshot，提供
跨期間的淨資產、資產類別、投資績效、收支、淨現金流、負債槓桿與現金覆蓋觀察。路由與錨定的決策理由見
[ADR-0090](adr/0090-report-analysis-single-route-and-anchor.md)；報表本身的語意見
[financial_report.md](financial_report.md)。

## 1. 分析錨點

分析頁錨定**最新且有資產負債表報表的期間，不論狀態**。範圍終點固定在錨點，不回推今天。

這與儀表板錨定最新已關帳月份刻意不同：儀表板是現況頁，分析頁是證據頁。錨點非已關帳時，
摘要句與 KPI 期間旁標示未關帳，頁面以資料截止列揭露日期與未關帳月份，區塊標題的值也加
「（未關帳）」。取捨見 [ADR-0053](adr/0053-dashboard-report-anchored.md) 與 ADR-0090。

沒有同月損益表時，儲蓄率顯示「—」，不往前找。完全沒有任何資產負債表時，整頁顯示空狀態。

報表中心 landing 的四格財務摘要共用同一條錨點規則，但只讀報表與財務期間，不讀
portfolio／snapshot，也不組其餘六條序列；錨點解析與 KPI 口徑共用同一份實作。

資料截止句固定揭露錨點與範圍內的未關帳期數。

頁面開頭先給結論再給證據：錨點淨資產、較上期變化率、儲蓄率、負債比；缺項略過，
上一期淨資產為 0 時不算變化率。摘要的版面見 [visual-standards.md](ui/visual-standards.md)。

## 1a. 選取期間

預設選取錨點。點選圖上任一期間（或鍵盤 Enter／空白鍵）即導覽到該期報表；`?period=` 則是
不導覽的深連結，解析後選取該期。選取是整頁共用狀態，所有圖表標記同一點，摘要句跟著它；
區塊標題則固定使用錨點期的值。`?period=` 無效時回到錨點。

未關帳期間在摘要列標「暫估」，tooltip 標題加「（未關帳）」。沒有該期資料的區塊在摘要列顯示
「—」。

## 1b. 資料粒度

年度是同一份月資料的聚合視角，不改變可畫期間或範圍；存量取該年最後一個月的值、流量取年度
加總，與報表歷史的年度透鏡（`/reports/YYYY`）是同一組語意。驗收條件見
[#357](https://github.com/manic1841/one-piece/issues/357)。

- **同一頁的年尺度**：`/reports/analysis?granularity=annual`，不新增路由、不加副標；年度報表
  `/reports/YYYY` 仍是獨立的下鑽目標。
- **入口兩處**：控制列的年度選取（範圍與粒度之後、`aria-label`「年度選取」、無可見標籤的
  `Select`），以及年度報表 header 的「查看年度分析」。報表歷史的年度列不加動作。
- **選取語意**：選年份即切到年粒度，只搬選取；不改錨點、不改範圍、不重新讀取、不捲動。
  年→月取該年在範圍內最晚的月份，沒有才退回錨點月；月→年取目前選取月份的年度，沒有選取則
  用錨點年。
- **參數以期間鍵形狀為準**：`?period=YYYY` 視為年粒度；`?granularity=monthly&period=YYYY`
  以鍵為準；非法 granularity 落回月。年粒度下的月鍵在網址改寫成所屬年度。
- **範圍邊界**：深連結年度落在範圍外時，進入時以 replace 擴到剛好含該年的最小可用範圍；使用者
  手動改範圍不自動擴。選取年被後續範圍變更排除時退回錨點年並改寫網址。
- **單一年度**：深連結仍可進入，控制列維持可見以便切回月，揭露列加「此範圍僅一個年度，年粒度
  只有一期；圖表需要兩期才成線。」；年度選取在年度少於兩個時隱藏。
- **揭露尺度**：年粒度下截止句加「（月尺度）」，未關帳清單仍以月份列出；錨點、KPI 與未關帳
  清單維持月尺度。
- **摘要句**：選取年沒有淨資產點時，摘要句改用該年之前最近的淨資產年；選取列仍以實際選取年
  為主，缺項「—」。

年度點仍下鑽該期報表（`/reports/YYYY`）；區塊標題值固定取錨點年，選取列與摘要句跟隨選取年。

## 2. 可畫期間

可畫期間是任何有該區塊所需報表型別的已產生報表月份，**不檢查財務期間狀態**。各區塊各自
只取有對應報表型別的月份：

| 區塊         | 報表型別                                  |
| ------------ | ----------------------------------------- |
| 淨資產       | 資產負債表                                |
| 資產類別構成 | 資產負債表，且資產總計大於 0              |
| 投資績效     | 資產負債表 ∩ 每個 portfolio 當月 snapshot |
| 收支         | 損益表                                    |
| 淨現金流     | 現金流量表                                |
| 負債與槓桿   | 資產負債表，且資產總計大於 0              |
| 現金覆蓋     | 資產負債表；缺三期損益表 window 時值為空  |

只有 snapshot 的月份不畫；snapshot 以既有 list-all 讀取後在範圍內過濾，不改 repository。
月彙總、snapshot 完整度與近三月現金覆蓋 window 由 workflow 編排，純函式只算值。

缺月份自軸省略、不補 0；軸僅由有報表的月份構成。區塊在目前範圍內可畫期間少於 2 期時顯示
「此範圍內不足 2 期」。

## 3. 指標

- **淨資產** ＝ 資產負債表資產總計 − 負債總計。
- **儲蓄率** ＝ (損益表收入總計 − 支出總計) ÷ 收入總計，顯示一位小數百分比。收入總計不大於 0
  時為空；負儲蓄率正常呈現為負值。口徑是應計基礎，不等於現金流。
- **淨現金流** ＝ 現金流量表淨現金變動，**以現金為基礎**。

## 4. 範圍

範圍以 replace 更新，終點固定錨點。依可用月份數去除產生相同結果的選項；有效選項只剩一個
時整條範圍控制隱藏。

## 5. 未關帳

範圍內的未關帳月份是暫定資料。圖上與範圍下方的標示方式見
[visual-standards.md](ui/visual-standards.md) 的 Analysis View；未關帳提示不使用 `Alert`，
`Alert` 只保留給載入錯誤。

## 6. 空值與狀態

KPI 缺對應報表時顯示「—」；資產或負債為 0 仍是合法序列。載入為各區塊 Skeleton、錯誤為
頂部 warning alert 與重試、空為共用空狀態。圖表 tooltip 只列目前可見序列，被關閉的序列不
進 tooltip、不影響軸範圍。

## 7. 資產類別構成

回答「資產以什麼形式持有」，與按標的看的持倉配置是兩個視角。

- 三條固定序列直接映射資產負債表的現金、投資與不動產三個資產群。
- 分母固定為資產總計，隨點帶出；佔比以「群值 ÷ 資產總計 × 100」計算，不重算分母。
- 圖例切換只影響可見性，**不重新歸一化**；可見序列的佔比因此可能合計不到 100%。
- 資產總計大於 0 才收；為 0 的月份視同缺月。群值可為負，照原值堆疊。
- 面積、y 軸與配色見 [visual-standards.md](ui/visual-standards.md) 的 Analysis View。

## 8. 投資績效

- 每點記該月報酬金額、期初市值與報酬率；報酬金額與期初市值為所有 portfolio 在該月的加總，
  報酬率為報酬金額 ÷ 期初市值 × 100，期初市值不大於 0 時為空。
- 口徑是家庭層「加總後相除」，不是各 portfolio 報酬率的平均。
- 只收同時有當月資產負債表、且**每個** portfolio 都有當月 snapshot 的月份；部分 portfolio
  缺 snapshot 時家庭加總會偏低，因此該月不收。完全沒有 snapshot 的 portfolio（剛建立）不計入
  這個交集，否則它會清空整段序列。
- 報酬金額與期初市值取自 snapshot 的 modified-Dietz 報酬，**已排除期間現金流**，因此家庭加總
  不會被存入或提出放大。
- 圖層配置見 [visual-standards.md](ui/visual-standards.md) 的 Analysis View。

## 9. 負債與槓桿

- 每點記負債、資產總計、負債比與加權平均槓桿；可畫期間為資產總計大於 0 的資產負債表月份，
  負債為 0 仍是合法點。
- 負債比 ＝ 負債 ÷ 資產總計 × 100；資產總計不大於 0 時為空（實務上已被可畫期間排除）。
- 加權平均槓桿是家庭持倉以市值加權的平均；該月無 snapshot、snapshot 不完整（部分 portfolio
  缺）或市值合計不大於 0 時為空，只斷槓桿線。不完整的月份不套用部分加總，避免低估曝險。
- 兩個比率意義不同：負債比是存量槓桿，加權平均槓桿是持倉曝險倍數，不得互相換算。
- 槓桿層只在目前範圍任一點的槓桿大於 1 時出現；否則不渲染該層，改在區塊底部說明
  「此範圍內持倉無槓桿」。

## 10. 現金覆蓋

回答「如果停下來能撐多久」，是全頁唯一的合成指標，也是最後一節。

- 每點記現金、月均支出與覆蓋月數；現金為當期資產負債表的現金群（含定存，缺席視為 0）。
- 月均支出為當月與前兩期支出總計的平均；覆蓋月數 ＝ 現金 ÷ 月均支出，月均支出不大於 0
  時為空。
- 任一期缺損益表時月均支出與覆蓋月數皆為空，該點斷線但仍留在軸上，不以「有幾期算幾期」補償。
- window 可由選取範圍外的既有損益表補齊；範圍只決定顯示軸。
- 可畫期間為任何資產負債表月份，不要求資產總計大於 0；覆蓋 0 個月是合法值。
- 非空點數少於 2 期時整區顯示「此範圍內不足 2 期」。年粒度取該年最後一個月的值。
- 標題小字與 tooltip 內容見 [visual-standards.md](ui/visual-standards.md)；底部固定公式註記。
