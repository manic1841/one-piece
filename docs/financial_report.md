# 財務報表 (Financial Reports)

三張報表都由分錄的科目推導，差別只在取用的科目範圍與分組。計算程式住在
`src/domains/report/`；資料結構見 [data-structure.md](data-structure.md)。

決策理由：手動產生見 [ADR-0018](adr/0018-manual-financial-report-generation.md)、
資產負債表混合制見 [ADR-0019](adr/0019-balance-sheet-hybrid-equity-derived.md)、
現金流量表兩種餘額見 [ADR-0020](adr/0020-cash-flow-ending-vs-actual-balance.md)。

## 1. 符號原則

報表層**只做加總，永不取絕對值**。方向由科目的正規邊決定——收入、負債、權益為貸方
正規；支出、資產為借方正規。借貸相抵後若為反向（沖銷、退款、提款、分紅），保留負值，
不靜默歸零，只濾零不濾負。

負數在 UI 以負號呈現；這條約束的是計算層，不是格式化。

## 2. 產生入口

正式報表只從關帳的 Financial Reports 階段產生。報表檢視頁只讀已產生報表，不做漂移
比對，也不提供產生入口；非已關帳期間的檢視頁以次級動作導回關帳。

產生前的就緒把關與關帳畫面永遠顯示預覽的語意，屬關帳工作流，見
[monthly-close.md](monthly-close.md) §3。

## 3. 損益表

收入取收入科目的貸方淨額、支出取支出科目的借方淨額，淨利為兩者相減。沖銷與退款保留
負值。

明細科目不獨立成列：父科目成列並加總，明細巢狀為子項。顯示標籤在產生時凍結進報表；
預覽每次重算時即時解析，因此同一列的標籤可能不同，漂移比對只比數字、不比標籤。

## 4. 資產負債表

帳戶餘額來自當月快照；其餘資產、負債、權益項目由分錄累加。資產必須恆等於負債加
權益：權益不從分錄計算，而是用資產減負債推算，確保永遠平衡。

權益拆為期初、本期淨利、資本、股票報酬與調整項目五個來源。調整項目理論上接近零；
偏大代表資料有誤，但系統無法定位是哪一筆，須人工追查。儲存端不寫任何權益餘額，
權益科目只是歸屬用。

不動產與資本不設第二層父列：group 本身就是 roll-up 層，明細直接記在 group 的項目裡。

## 5. 現金流量表

只篩現金類資產的分錄，依營業、投資、融資分組。系統另行比對「算出的期末現金」與
「資產負債表的現金總額」；不符代表科目標記或快照不一致，由使用者自行判斷修正，不
定位到單一帳戶。

明細科目採與損益表相同的 roll-up 與標籤規則。

## 6. 儀表板錨定

儀表板整頁錨定**最新已關帳月份**。

- 淨資產只有一條路徑：錨定月份的資產負債表權益。
- 四個脈動指標全部錨定同一月份：淨現金流、投資報酬、投資槓桿、當月債務支出。
- 缺月或缺指標顯示破折號，不顯示 0。

兩個例外必須獨立、具名、標示前瞻：近期交易是最新事件的即時流；下月應付由債務條件
推導。取捨見 [ADR-0053](adr/0053-dashboard-report-anchored.md)。
