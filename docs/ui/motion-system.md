# 動態系統 (Motion System)

> **邊界宣告**：本文件管**全站動態契約**——動態方向、token 的用途對應、全域規則、動畫清單、已確認場景、頁面層級套用、無障礙與效能。**色彩／材質／字體排印／元件尺寸等靜態表面**屬 [`design-system.md`](design-system.md)；**頁面層級佈局**屬 [`visual-standards.md`](visual-standards.md)；**三態義務與無障礙契約**屬 [`states-and-a11y.md`](states-and-a11y.md)。五份文件權威不重疊。

**值與規範的分工**：本文件寫 token 的**用途、對應與禁止事項**，值一律以 `tailwind.config.js`、`src/index.css` 為準。出現數值只有兩種情形——拿掉它這句話就講不通（門檻、位移量），或它記錄的是 code 推不回的來源——兩者都標明為對照，牴觸時以 code 為準。

**單一實作**：全站只實作本文件列出的動態。新增一項動態前先確認它落在 §4 的某一列；落不進去就是新決策，走 `development-guide.md` §4 的流程。

**與 gallery 的分工**：`/gallery` 第 37 節 Motion Lab 是本文件的手動驗證場，呈現的是本文件的契約，不是第二份規格。表面衝突以本文件為準。

## 1. 方向

**精確優先 × 物理但不好玩 × 選擇性粒子。**

- **精確優先**：動態傳達狀態變化與關係，不裝飾每個表面。
- **物理但不好玩**：需要時用克制的慣性與阻尼；財務數字不加回彈。
- **動態有層級**：微互動最短、浮出層清楚、資料變化可讀、品牌效果限定場景。
- **資料誠信優先**：永不過渡到應用程式尚未確認的狀態。載入、成功、失敗是三種不同狀態。

## 2. Token

Token 全部定義於 `tailwind.config.js`，值不複述。只有一條事實：**一個 token 對應一類場景，不得跨類挪用**。

| Token                | 對應                              | 禁止用於            |
| -------------------- | --------------------------------- | ------------------- |
| `duration-fast`      | 按壓回饋、hover、focus、小狀態切換 | 浮出層進出          |
| `duration-base`      | 開合、色彩過渡、本地狀態切換       | 資料補間            |
| `duration-slow`      | 位移、materialize、浮出層進出      | 按壓回饋            |
| `duration-data`      | 已確認數值的補間                   | 任何位移或開合      |
| `ease-out-quint`     | 進場、展開、放開後回彈             | 退場                |
| `ease-in-quint`      | 退場                              | 進場                |

- 可逆轉換（開 ↔ 關、進 ↔ 退）必須鏡像 easing；單向回饋（hover、focus）用單一 `ease-out`。
- 鏡像不等於把曲線左右翻。退場起手慢是為了「不是被抽走」，但字面的 `ease-in-quint` 會讓前 3/4 的時間幾乎不動、最後 100ms 才衝完，體感比進場久兩、三倍。所以退場曲線取同家族但更溫和的形狀（控制點見 `motion.constants.ts`），仍屬「慢起、快收」。
- 同一個浮出層的遮罩與內容必須用同一組曲線，否則兩條節奏打架，內容的曲線再怎麼調都看不出來。
- `duration-data` 固定搭配 `ease-out-quint`，不另設 `ease-data`：終值停留時間最長，讀者最先讀到的是「已經快到了」。

`requestAnimationFrame` 讀不到 CSS 曲線與 `ms` 字串，兩者另在 `src/ui/motion.constants.ts` 以數值保存；`tailwind.config.js` 由同一張表產生 token，值不會兩地各寫一份。

## 3. 全域規則

- 只動 `transform`、`opacity`、`backdrop-filter`；不逐幀動 layout 屬性。
- 一般進場位移 4–12px；資料表與財務數字保持空間穩定。
- 按壓縮放 `scale(0.97)` 留給按鈕、icon 與小型控制；列、input 形狀的欄位與底線式 tabs 靠底色／字色變化，不縮放以避免大面積位移。
- 不縮放重要的財務值。
- 優先自然減速，不用 overshoot。彈性保留給直接操作（bottom sheet 拖曳）。
- `primary` 是聚焦強調色，不是每個元件的發光色。
- 不為每次小型資料刷新重播頁面進場。
- 鍵盤操作與焦點可見性不受動態影響；動態不得阻塞提交、捲動或連續輸入。
- 尊重 `prefers-reduced-motion`：關掉非必要的位移與連續效果，保留狀態回饋（見 §7）。
- 場景隱藏或已無關時停止非必要的動畫迴圈。

## 4. 動畫清單

優先序：**P0 核心**（一致互動所需）、**P1 產品動態**（實際的資料回饋或已確認的互動）、**P2 品牌點綴**（限定場景）。

| ID  | 動畫                | 觸發                   | 行為                                         | 優先 |
| --- | ------------------- | ---------------------- | -------------------------------------------- | ---- |
| M01 | Hover / Focus       | 指標或鍵盤聚焦         | 邊框、表面或 focus ring 過渡                 | P0   |
| M02 | 按壓                | 按下／放開             | 極短 press scale 後回復                      | P0   |
| M03 | Modal / Drawer      | 開／關                 | 小位移＋透明度；退場穩定                     | P0   |
| M04 | 頁面內容進場        | 實際路由切換           | 內容淡入＋克制位移                           | P0   |
| M05 | 展開 / 收合         | 使用者切換區塊         | 高度／內容過渡，欄位順序不變                 | P0   |
| M06 | 表格更新            | 已確認的新增／移除／排序 | 只動受影響的列，可做到才做                   | P0   |
| M07 | 財務數字            | 已確認的資料刷新       | 在已確認的新舊值之間補間                     | P1   |
| M08 | 圖表揭露            | 有效圖表資料首渲染     | 由基線長出；無 overshoot                     | P1   |
| M09 | 操作回饋            | 儲存、關帳、備份、計算 | 明確的 pending／success／error 狀態轉換      | P1   |
| M10 | Bottom Sheet 物理   | 直接觸控／指標拖曳     | 跟手；放開後依門檻關閉或以阻尼回位           | P1   |
| M11 | Orbit Loading       | 真實非同步任務 pending | 小型環形指示＋明確狀態文字；結束即停         | P1   |
| M12 | 品牌粒子場          | 限定場景               | 稀疏、低對比粒子；只在可見時執行             | P2   |

Pixel Pet 的反應動畫另案討論，不在本清單：它的反應由具名事件觸發，但點陣、frame 幾何與播放都由 pet 自己擁有，UI 不控制單一 frame。Pixel Pet 固定在 `position: fixed`，因此**不參與本文件任何頁面層級的動態編排**。

## 5. 已確認場景

### 5.1 UI 微互動

按壓、hover／focus、modal、表單聚焦、展開／收合共用 §2 的 token，不各自調參。

### 5.2 資料動態

- 只在資料狀態可用後才動。
- 後續的篩選／日期變更更新既有圖表，不重播整頁進場。
- 不暗示資料集沒有的數值或趨勢。
- 標籤、軸、數值在過渡中全程可讀。

**數字補間（M07）的範圍**：只有單一醒目數字——Dashboard 的指標與 hero、明細頁的總額（帳戶餘額、債務餘額）。表格一次更新多列，補間會讓整張表同時跳動並破壞掃視比對，因此不套。金額一律 `tabular-nums` 避免寬度抖動；補間期間不顯示 tooltip 數值。

### 5.3 Bottom Sheet 物理

適用於所有 `side="bottom"` 的 sheet，預設開啟；水平 sheet 不受影響。取捨與被否決的方案見 [ADR-0091](../adr/0091-draggable-bottom-sheet-without-animation-library.md)。

- **只有 drag handle 是拖曳區**，sheet 內容照常捲動。handle 是純視覺提示、`aria-hidden`；鍵盤仍靠 Escape 與 Close 按鈕。
- handle 帶固定在捲動區之外，捲動時不隨內容移動，因此內容捲到任何位置都能拖。
- 拖曳中直接映射 `translateY`，不加 easing——手指就是時鐘。上拖夾制在高度 20%，避免把 sheet 拉離版位。
- 放開時，位移達 sheet 高度 25% **或**向下速度達 0.5 px/ms 即關閉；否則以 `duration-slow` + `ease-out-quint` 歸位。
- **退場的 transform 由手勢獨佔**：可拖的 sheet 在關閉狀態停用自身的進場／退場 keyframe，改由手勢把 sheet 帶離畫面，移動結束才宣告關閉。若先清掉 transform 再交給浮出層自己的退場動畫，sheet 會從原點重播一次、變成離開兩次。
- reduced motion 下，歸位與離場以單一影格完成，不等 `duration-slow`。
- **手勢只決定「怎麼關」，不決定「關不關得成」**：一律走呼叫端既有的關閉函式，元件不感知 dirty，也不新增確認。需要 dirty 保護時由呼叫端在自己的關閉函式裡加。
- 遮罩與 sheet 必須有清楚的開啟／關閉狀態；sheet 開啟時背景不捲動。

### 5.4 Orbit Loading

只用於長到值得顯示 pending 的真實非同步操作（退休投影計算、資料庫備份）。

- 指示器旁邊一定有明確狀態文字，例如「正在計算投影…」。
- 只在操作 pending 時啟動；成功、失敗、取消立即停止。
- 瞬時操作不用迴圈指示器。
- 底層沒有回報真實進度時，不宣稱百分比。

### 5.5 品牌粒子場

實驗性場景，**只存在 gallery**，不進日常財務流程。

- 密度與對比低，`primary` 節制使用。
- 場景隱藏或頁面不可見時暫停。
- 不做逐粒子 blur 或 layout 效果。
- `prefers-reduced-motion` 下凍結或移除連續運動。
- 這是實驗，不是新增品牌入口頁的理由。

### 5.6 頁面進場

路由切換時，新頁內容淡入並上移 6px，`duration-base` + `ease-out-quint`，套在 `Layout` 的內容區。

- **只有進場，沒有出場。** React Router 沒有出場階段，舊頁在新頁 render 的同一影格就卸載；做出場等於要保留舊樹或改用 View Transitions API，是比 M04 更大的決策。
- **觸發鍵是路由樣式，不是 `pathname`。** `/reports/:period`、`/accounts/:id` 這類只換參數的導覽屬 §5.2 的「更新既有內容」，不重播進場。搜尋字串同樣不觸發。
- 浮出層（modal、sheet）與頁內篩選不重播；兩者的動態各自歸屬 M03、M06。
- 進場只動 `opacity` 與 `transform`，不影響捲動位置與版面高度。
- 動畫結束後不留下 `transform`：完成的 transform 仍算一個值，會讓容器變成 `fixed` 子元素的定位基準（Dashboard 的背景格線就是）。因此用 `backwards` 而非 `both`，終點回到元素原本的樣式。
- reduced motion 由 §7 的全域規則抹成瞬時，不留位移。

## 6. 頁面層級套用

| 區域     | 要用                                         | 不要用                                  |
| -------- | -------------------------------------------- | --------------------------------------- |
| Dashboard | 初次圖表揭露；已確認指標的數值更新           | 每次刷新重播全部動畫                    |
| 交易     | 表單／浮出層動態；本地列更新；儲存回饋       | 每筆輸入後整表位移                      |
| 報表     | 初次圖表揭露；穩定 tooltip；克制的期間更新   | 妨礙比較或暗示假趨勢的動態              |
| 退休     | 計算完成後的結果更新；真正的 pending 用 Orbit | 計算完成前先更新結果                    |
| 設定     | 開關、揭露、備份狀態回饋                     | 裝飾性粒子或慶祝效果                    |
| 關帳     | 步驟／狀態轉換；有真實狀態依據才顯示進度     | 操作成功前先顯示完成                    |
| 行動導覽 | sheet 拖曳、門檻、阻尼歸位                   | 把彈性套到無關的 UI                     |

## 7. 無障礙與效能

### Reduced motion

`prefers-reduced-motion: reduce` 由 `src/index.css` 的全域規則一刀切為近乎瞬時。這是最不容易寫錯的處置，也符合資料優先。

- 直接操作不算動畫：sheet 的跟手拖曳照常，只有放開後的歸位被抹成瞬時。
- `requestAnimationFrame` 驅動的值補間不受全域 CSS 規則約束（rAF 不是 CSS）：元件自己讀一次媒體查詢，命中時直接跳到終值。
- 保留立即的狀態變化、可見焦點、進度與狀態文字、所有控制項。
- 有 `motion-safe` 變體時優先用它，而不是在元件內讀媒體查詢。

### 效能

- 只動合成層友善的 `transform` 與 `opacity`。
- 粒子數與 DPR 縮放設上限；上線前在目標裝置 profiling。
- 場景隱藏或頁面不可見時暫停 `requestAnimationFrame` 迴圈。
- 卸載時清掉 listener、observer 與動畫迴圈。
- 連續動 `height`、`filter` 或大面積陰影前先量測。
