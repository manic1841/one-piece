# 動態系統 (Motion System)

> **邊界宣告**：本文件管**全站動態契約**——動態方向、token 的用途對應、全域規則、動畫清單、已確認場景、頁面層級套用、無障礙與效能。**色彩／材質／字體排印／元件尺寸等靜態表面**屬 [`design-system.md`](design-system.md)；**頁面層級佈局**屬 [`visual-standards.md`](visual-standards.md)；**三態義務與無障礙契約**屬 [`states-and-a11y.md`](states-and-a11y.md)。五份文件權威不重疊。

**值與規範的分工**：本文件寫 token 的**用途、對應與禁止事項**，值一律以 `tailwind.config.js`、`src/index.css` 為準。出現數值只有兩種情形——拿掉它這句話就講不通（門檻、位移量），或它記錄的是 code 推不回的來源——兩者都標明為對照，牴觸時以 code 為準。

**單一實作**：全站只實作本文件列出的動態。新增一項動態前先確認它落在 §4 的某一列；落不進去就是新決策，走 `development-guide.md` §4 的流程。

**與 gallery 的分工**：`/gallery` 第 37 節 Motion Lab 是本文件的手動驗證場，呈現的是本文件的契約，不是第二份規格。表面衝突以本文件為準。

## 1. 方向

**精確優先 × 物理但不好玩 × 選擇性粒子。**

- **精確優先**：動態傳達狀態變化與關係，不裝飾每個表面。
- **物理但不好玩**：需要時用克制的慣性與阻尼；財務數字不加回彈。
- **動態有層級**：微互動最短、浮出層清楚、資料變化可讀、品牌效果限定場景。
- **資料誠信優先**：永不過渡到應用程式尚未確認的狀態。載入、成功、失敗是三種不同狀態。

## 2. Token

Token 全部定義於 `tailwind.config.js`，值不複述。只有一條事實：**一個 token 對應一類場景，不得跨類挪用**。

| Token               | 對應                                | 禁止用於       |
| ------------------- | ----------------------------------- | -------------- |
| `duration-fast`     | 按壓回饋、hover、focus、小狀態切換  | 浮出層進出     |
| `duration-base`     | 色彩過渡、本地狀態切換              | 資料補間       |
| `duration-slow`     | 位移、materialize、浮出層進出、揭露 | 按壓回饋       |
| `duration-data`     | 已確認數值的補間                    | 任何位移或開合 |
| `duration-expand`   | 展開                                | 收合           |
| `duration-collapse` | 收合                                | 展開           |
| `ease-expand`       | 展開、揭露                          | 收合           |
| `ease-collapse`     | 收合                                | 展開           |
| `ease-out-settle`   | 浮出層進場、頁面進場                | 退場           |
| `ease-out-quint`    | 放開後回彈、微互動                  | 退場           |
| `ease-in-quint`     | 浮出層退場                          | 進場           |

- **開合是唯一不對稱的動態。** 展開要交出資訊，所以較長；收合只是移除，較短。兩者差距約 50ms，感知的是「俐落」而不是「變快」。
- **長度與曲線要一起看。** 曲線決定眼睛實際等多久：把變化全塞進前段的曲線會讓設定得較長的展開讀起來比設定得較短的收合還短。所以開合不共用 `ease-out-settle`／`ease-in-quint`，各自有方向正確的 `ease-expand`（前期保留）與 `ease-collapse`（前期花掉），順序由 `motion.test.ts` 釘住。
- 可逆轉換（開 ↔ 關、進 ↔ 退）必須鏡像 easing；單向回饋（hover、focus）用單一 `ease-out`。
- 鏡像不等於把曲線左右翻。退場起手慢是為了「不是被抽走」，但字面的 `ease-in-quint` 會讓前 3/4 的時間幾乎不動、最後 100ms 才衝完，體感比進場久兩、三倍。所以退場曲線取同家族但更溫和的形狀（控制點見 `motion.constants.ts`）。
- 同一個浮出層的遮罩與內容必須用同一組曲線，否則兩條節奏打架，內容的曲線再怎麼調都看不出來。
- `duration-data` 固定搭配 `ease-out-quint`，不另設 `ease-data`：終值停留時間最長，讀者最先讀到的是「已經快到了」。

`requestAnimationFrame` 讀不到 CSS 曲線與 `ms` 字串，兩者另在 `src/ui/motion.constants.ts` 以數值保存；`tailwind.config.js` 由同一張表產生 token，值不會兩地各寫一份。

## 3. 全域規則

- 只動 `transform`、`opacity`、`backdrop-filter`；不逐幀動 layout 屬性。
- 一般進場位移 4–12px；資料表與財務數字保持空間穩定。
- 按壓縮放 `scale(0.97)` 留給按鈕、icon 與小型控制；列、input 形狀的欄位與底線式 tabs 靠底色／字色變化，不縮放以避免大面積位移。
- 不縮放重要的財務值。
- 優先自然減速，不用 overshoot。彈性保留給直接操作（bottom sheet 拖曳）。
- `primary` 是聚焦強調色，不是每個元件的發光色。
- 不為每次小型資料刷新重播頁面進場。
- 鍵盤操作與焦點可見性不受動態影響；動態不得阻塞提交、捲動或連續輸入。
- 尊重 `prefers-reduced-motion`：關掉非必要的位移與連續效果，保留狀態回饋（見 §7）。
- 場景隱藏或已無關時停止非必要的動畫迴圈。

## 4. 動畫清單

優先序：**P0 核心**（一致互動所需）、**P1 產品動態**（實際的資料回饋或已確認的互動）、**P2 品牌點綴**（限定場景）。

| ID  | 動畫              | 觸發                     | 行為                                    | 優先 |
| --- | ----------------- | ------------------------ | --------------------------------------- | ---- |
| M01 | Hover / Focus     | 指標或鍵盤聚焦           | 邊框、表面或 focus ring 過渡            | P0   |
| M02 | 按壓              | 按下／放開               | 極短 press scale 後回復                 | P0   |
| M03 | Modal / Drawer    | 開／關                   | 小位移＋透明度；退場穩定                | P0   |
| M04 | 頁面內容進場      | 實際路由切換             | 內容淡入＋克制位移                      | P0   |
| M05 | 展開 / 收合       | 使用者切換區塊           | 高度／內容過渡，欄位順序不變            | P0   |
| M06 | 表格更新          | 已確認的新增／移除／排序 | 只動受影響的列，可做到才做              | P0   |
| M07 | 財務數字          | 已確認的資料刷新         | 在已確認的新舊值之間補間                | P1   |
| M08 | 圖表揭露          | 有效圖表資料首渲染       | 由基線長出；無 overshoot                | P1   |
| M09 | 操作回饋          | 儲存、關帳、備份、計算   | 明確的 pending／success／error 狀態轉換 | P1   |
| M10 | Bottom Sheet 物理 | 直接觸控／指標拖曳       | 跟手；放開後依門檻關閉或以阻尼回位      | P1   |
| M11 | Orbit Loading     | 真實非同步任務 pending   | 小型環形指示＋明確狀態文字；結束即停    | P1   |
| M12 | 品牌粒子場        | 限定場景                 | 稀疏、低對比粒子；只在可見時執行        | P2   |

## 5. 已確認場景

### 5.1 UI 微互動

按壓、hover／focus、modal、表單聚焦、展開／收合共用 §2 的 token，不各自調參。

**展開／收合（M05）走漸進揭露 ＋ 空間連續性**：內容從標題列的位置長出來，收合時有秩序地退回同一處，不是被抽走或淡掉。

- 只動容器高度、`opacity`、`transform`。`translateY` 由上方 −4px 滑入，收合退到 −2px。
- 收合比展開短（`duration-collapse` 對 `duration-expand`）：展開要讓人讀完新資訊，收合只是移除。
- 兩半的曲線不得顛倒（`ease-expand` 對 `ease-collapse`）：展開要在時間用完前都還看得到在動，收合要立刻離開。只改長度不改曲線，或兩半共用一條前載曲線，都會讓展開的體感比收合短。
- 容器外框、邊框、欄位順序在過渡期間完全不動；只有高度在變。
- **keyframe 恆綁在 state 上，不特判「切換才開始」。** 首渲染時展開的區塊播展開、收合的播收合，動態因此每次載入都重演，與 M07 的立場一致。代價是報表這類同頁多個收合區塊會一起播一輪；接受它，換來實作只有一條路徑。
- chevron 同步轉 180°、`duration-fast`。
- 收合後的內容必須離開 tab 順序與 a11y 樹（`inert`）——只把高度收成 0 仍讀得到、tab 得到。
- 用 `ui/accordion` 時由 Radix 的 `--radix-accordion-content-height` 取得高度；手寫的揭露區塊插值 `height: auto ↔ 0`，並靠 `interpolate-size: allow-keywords` 讓 `auto` 可插值，不寫 JS 量測。
- **不要用 `grid-template-rows: 0fr → 1fr` 收合。** 容器 `height` 是 `auto` 時 `fr` 沒有確定高度可解析，收合值會停在內容高度——動畫播完就彈回，看起來像「摺疊後留下空白列」。同理，列若還帶著自己的固定列高（如 `h-[54px]`），第一影格就跳到位，只剩被裁切的內容在動；高度要一律交給內容。
- **`interpolate-size` 只有 Chromium 支援**（Chrome 129+，Firefox 與 Safari 都沒有，含 iOS）。沒有它時 keyframe 裡的高度會退化成離散動畫：展開的前半段高度停在 0、內容整個看不到，然後才跳出來，比不做還糟。`index.css` 因此在 `@supports not (interpolate-size: allow-keywords)` 下換成純淡入／淡出的 keyframe，讓高度立刻到位；新增這類揭露區塊時別漏掉同一個 fallback。
- 沒有 `interpolate-size` 的引擎仍會留下行高 1px（表格列的最小高度），單層無感，深層區塊收合會疊出幾 px 空白。這是刻意的取捨，不是回歸。
- reduced motion 由 §7 全域規則抹成瞬時。

### 5.2 資料動態

- 只在資料狀態可用後才動。
- 後續的篩選／日期變更更新既有圖表，不重播整頁進場。
- 不暗示資料集沒有的數值或趨勢。
- 標籤、軸、數值在過渡中全程可讀。

**數字補間（M07）的判準：這個數字是它那個區塊的主題，就套。** 金額、比率與計數都算。不套的是——表格**列內**的數字，一次更新多列會讓整張表同時跳動、破壞掃視比對；`change` 之類的衍生文字、日期、年份、帳戶類型與幣別。不維護套用清單，畫面怎麼改判準都一樣。金額與比率一律 `tabular-nums` 避免寬度抖動；補間期間不顯示 tooltip 數值。

**每一次載入都從 0 起算。** 從 0 起算等於宣稱「這筆錢是從 0 長上來的」，這在跨月淨資產上不是事實；但計數是可讀的開場，而重新載入若接在舊值後面補間，兩次載入會被讀成同一個連續事件。所以一律從 0 起算，符合判準的每一處都掛 `animateOnMount`。

值在掛載後才抵達（中繼資料與快照分開載入）仍算首次出現，`animateOnMount` 一樣會從 0 起算——專案的餘額與退休的計算結果都靠這條規則，否則它們會永遠停在初始的空值。

**骨架因此綁在 `loading` 上**，不判斷「是不是第一次載入」：重新載入時數字重新掛載、重新從 0 起算，這就是「每次載入都會動」的來源。代價是重新載入會短暫看到骨架，是刻意的取捨。數值與 `animateFormat` 必須成對提供，否則補間只會停在原始數字。Dashboard 以外的補間要有**原地觸發**才看得到（例如退休年度的年份切換）；整頁換路由屬於 M04，不算。

### 5.3 Bottom Sheet 物理

適用於所有 `side="bottom"` 的 sheet，預設開啟；水平 sheet 不受影響。取捨與被否決的方案見 [ADR-0091](../adr/0091-draggable-bottom-sheet-without-animation-library.md)。

- **只有 drag handle 是拖曳區**，sheet 內容照常捲動。handle 是純視覺提示、`aria-hidden`；鍵盤仍靠 Escape 與 Close 按鈕。
- handle 帶固定在捲動區之外，捲動時不隨內容移動，因此內容捲到任何位置都能拖。
- 拖曳中直接映射 `translateY`，不加 easing——手指就是時鐘。上拖夾制在高度 20%，避免把 sheet 拉離版位。
- 放開時，位移達 sheet 高度 25% **或**向下速度達 0.5 px/ms 即關閉；否則以 `duration-slow` + `ease-out-quint` 歸位。
- **退場的 transform 由手勢獨佔**：可拖的 sheet 在關閉狀態停用自身的進場／退場 keyframe，改由手勢把 sheet 帶離畫面，移動結束才宣告關閉。若先清掉 transform 再交給浮出層自己的退場動畫，sheet 會從原點重播一次、變成離開兩次。
- reduced motion 下，歸位與離場以單一影格完成，不等 `duration-slow`。
- **手勢只決定「怎麼關」，不決定「關不關得成」**：一律走呼叫端既有的關閉函式，元件不感知 dirty，也不新增確認。需要 dirty 保護時由呼叫端在自己的關閉函式裡加。
- 遮罩與 sheet 必須有清楚的開啟／關閉狀態；sheet 開啟時背景不捲動。

### 5.4 Orbit Loading

只用於長到值得顯示 pending 的真實非同步操作（退休投影計算、資料庫備份）。

- 指示器旁邊一定有明確狀態文字，例如「正在計算投影…」。
- 狀態文字放在 live region（`role="status"`）裡供讀出，但 **live region 不計入外層按鈕的可存取名稱**；動作按鈕要自己帶上與可見文字相同的 `aria-label`，否則 pending 期間按鈕是無名的。
- 只在操作 pending 時啟動；成功、失敗、取消立即停止。
- 瞬時操作不用迴圈指示器。
- 底層沒有回報真實進度時，不宣稱百分比。

### 5.5 品牌粒子場

實驗性場景，**只存在 gallery**，不進日常財務流程。

- 密度與對比低，`primary` 節制使用。
- 場景隱藏或頁面不可見時暫停。
- 不做逐粒子 blur 或 layout 效果。
- `prefers-reduced-motion` 下凍結或移除連續運動。
- 這是實驗，不是新增品牌入口頁的理由。

### 5.6 頁面進場

路由切換時，新頁內容淡入並上移 6px，`duration-slow` + `ease-out-settle`，套在 `Layout` 的內容區。

- **曲線與長度一起定，不是分開調的兩個旋鈕。** `ease-out-quint` 把九成變化壓進前四分之一，在 240ms 下讀起來就是硬切；把同一條曲線拉長只是等比例放大這個偏斜。`ease-out-settle` 把變化攤在前四分之三、只留一段柔性收尾，位移因此在前 300ms 內就讀得完，剩下的回合是收邊。換長度時要一併檢查曲線是否還撐得住。

- **只有進場，沒有出場。** React Router 沒有出場階段，舊頁在新頁 render 的同一影格就卸載；做出場等於要保留舊樹或改用 View Transitions API，是比 M04 更大的決策。
- **觸發鍵是路由樣式，不是 `pathname`。** `/reports/:period`、`/accounts/:id` 這類只換參數的導覽屬 §5.2 的「更新既有內容」，不重播進場。搜尋字串同樣不觸發。
- 浮出層（modal、sheet）與頁內篩選不重播；兩者的動態各自歸屬 M03、M06。
- 進場只動 `opacity` 與 `transform`，不影響捲動位置與版面高度。
- 動畫結束後不留下 `transform`：完成的 transform 仍算一個值，會讓容器變成 `fixed` 子元素的定位基準（Dashboard 的背景格線就是）。因此用 `backwards` 而非 `both`，終點回到元素原本的樣式。
- reduced motion 由 §7 的全域規則抹成瞬時，不留位移。

### 5.7 圖表揭露

圖表第一次拿到有效資料時，數列由基線長出來，`duration-slow` + `ease-expand`。四個圖表元件（`LineChart`、`ComposedChart`、`BarChart`、`DonutChart`）一律揭露，沒有開關；互動版（`InteractiveLineChart`、`InteractiveBarChart`、`InteractiveComposedChart`）同樣，換成互動版也不會失去揭露。

- **觸發鍵只有「有效資料首渲染」。** 圖表本身在骨架與內容之間是條件渲染，資料一到就是掛載，所以揭露直接綁在掛載上；期間切換、hover、tooltip 都是重繪而非重掛，不會重播。
- **折線由其面積所在的基線長出＝一個自下而上的 clip rect**，套在整個數列群組外，線與其面積一起被揭露、保持貼合。clip 不會拉寬 stroke；`pathLength` + dash 則是沿著線跑、不是由基線，且 `preserveAspectRatio="none"` 會讓 dash 長度失真。
- **零線落在中間的圖形反過來用 `scaleY`。** clip 只能往一個方向長，負值會先整條出現；`ComposedChart` 因此以零線為 `transform-origin`（`transform-box: view-box`）縮放數列群組，正負兩側同時長出。縮放會連線寬一起拉，靠 `vector-effect="non-scaling-stroke"` 抵銷——沒有這個屬性就不要改用縮放。
- **`BarChart` 的值是量級**，只有一個方向，縮放起點就是底線，`origin-bottom` 即可。
- **`DonutChart` 的環是背景**，縮放會連中間的洞與數字一起動，所以改用被遮罩的 conic 停角（`@property --chart-sweep`）掃開。沒有 `@property` 的引擎不補間角度、會在中點跳到整圈，落點仍然正確。
- **沒有 overshoot**：`ease-expand` 對稱，起點與終點都停得住；數列應該落在資料上，不該彈過頭再回來。
- 只有一個點時沒有線可長，直接顯示；空幾何不掛揭露。
- 格線、零線、參考線、軸標籤維持靜態，它們是座標系而不是資料；參考線先站好，數列再長上去與它會合。
- reduced motion 由 §7 的全域規則抹成瞬時，因此揭露不必自己讀媒體查詢。

## 6. 頁面層級套用

| 區域      | 要用                                          | 不要用                     |
| --------- | --------------------------------------------- | -------------------------- |
| Dashboard | 初次圖表揭露；已確認指標的數值更新            | 每次刷新重播全部動畫       |
| 交易      | 表單／浮出層動態；本地列更新；儲存回饋        | 每筆輸入後整表位移         |
| 報表      | 初次圖表揭露；穩定 tooltip；克制的期間更新    | 妨礙比較或暗示假趨勢的動態 |
| 退休      | 計算完成後的結果更新；真正的 pending 用 Orbit | 計算完成前先更新結果       |
| 設定      | 開關、揭露、備份狀態回饋                      | 裝飾性粒子或慶祝效果       |
| 關帳      | 步驟／狀態轉換；有真實狀態依據才顯示進度      | 操作成功前先顯示完成       |
| 行動導覽  | sheet 拖曳、門檻、阻尼歸位                    | 把彈性套到無關的 UI        |

## 7. 無障礙與效能

### Reduced motion

`prefers-reduced-motion: reduce` 由 `src/index.css` 的全域規則一刀切為近乎瞬時。這是最不容易寫錯的處置，也符合資料優先。

- 直接操作不算動畫：sheet 的跟手拖曳照常，只有放開後的歸位被抹成瞬時。
- `requestAnimationFrame` 驅動的值補間不受全域 CSS 規則約束（rAF 不是 CSS）：元件自己讀一次媒體查詢，命中時直接跳到終值。
- 保留立即的狀態變化、可見焦點、進度與狀態文字、所有控制項。
- 有 `motion-safe` 變體時優先用它，而不是在元件內讀媒體查詢。

### 效能

- 只動合成層友善的 `transform` 與 `opacity`。
- 粒子數與 DPR 縮放設上限；上線前在目標裝置 profiling。
- 場景隱藏或頁面不可見時暫停 `requestAnimationFrame` 迴圈。
- 卸載時清掉 listener、observer 與動畫迴圈。
- 連續動 `height`、`filter` 或大面積陰影前先量測。
