**狀態：** 提議中 / 已接受 / 已實作 / 已被 ADR-NNNN 取代

## Considered Options

只在被否決的方案值得被記住時才寫。

## Consequences

只在有非顯而易見的下游效應、債務或例外時才寫。

## Revisit When

只在能預先說出「什麼條件成立時這個決策該被重新檢視」時才寫。
