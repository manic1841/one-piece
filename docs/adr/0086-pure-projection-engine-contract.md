# 投影引擎是純函式，只接受已解析的逐年時間軸

**日期：** 2026-10-20
**狀態：** 已接受
**規範來源：** [retirement-system.md](../retirement-system.md) §7

投影引擎只收兩樣東西：期初餘額，以及已經逐年解析完成的金額時間軸。它不認識 Method、來源、規則或 Firestore，也不呼叫時鐘。規則展開由解析層負責，引擎只負責把每年的金額推進成淨資產：報酬套用在期初餘額上，破產後仍繼續算到期滿、缺口以負值保留而不歸零。

理由是引擎的正確性只有「數字對不對」一種，把它和來源查詢、拓撲排序綁在一起就無法用純資料測邊界。破產不歸零是為了讓後續年度的缺口累積看得見；歸零會讓之後每一年的結果都變成假的。

輸出含逐年 breakdown 與六欄 summary，可缺值的欄位用 `null` 而不是 0，讓「不知道」與「算出來是零」在型別上分得開。
