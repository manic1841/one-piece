# 收入匯入固定採上一個完整年度年化計算

**狀態：** 已接受
**規範來源：** [retirement-system.md](../retirement-system.md) §3

退休收入匯入固定使用上一個完整年度：查詢該年度的交易、展開分錄、篩選收入科目後依科目分組加總。匯入結果以來源年度標記，並年化為月平均。

只統計收入科目，避免將資產或負債分錄誤算為收入；以貸方減借方計算則可維持收入方向正確。

**修訂（ADR-0085）：** 匯入仍固定取上一個完整年度，但結果存為年度總額，不再年化為月平均——新模型的每一條規則都在年度粒度上推導，月平均只是中間量。「以來源年度標記」也退場，投影改以基準引用記錄科目與年份。
