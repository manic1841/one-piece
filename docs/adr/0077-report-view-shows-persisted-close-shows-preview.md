# 同一期間的報表在關帳與報表檢視是兩種契約：預覽＋漂移 vs 已產生報表

**日期：** 2026-10-05
**狀態：** 已實作
**規範來源：** [financial_report.md](../financial_report.md) §0「報表產生前置檢查」

報表檢視（歷史脈絡）一律讀已產生報表、不做漂移比對；月度關帳畫面一律顯示即時預覽並逐欄標註漂移（見 [ADR-0071](0071-close-shows-preview-with-drift.md)）。兩者服務不同目的：關帳要看到「現在算出來是多少、與定案差多少」，報表檢視要看到「當時定案的紀錄不受後續改動影響」。因此非已關帳期間若有殘存的已產生報表，兩個畫面會顯示不同數字——這是刻意的，不是缺陷。

## Considered Options

- 報表檢視也顯示預覽或也做漂移：否決，歷史紀錄必須穩定，且漂移是關帳的決策工具，不是回看的內容。
- 關帳改顯示已產生報表：否決，違反 ADR-0071，關帳將失去「產生後改了什麼」的可見性。

## Consequences

- 同一期間兩畫面數字可能不同，兩邊都必須維持清楚的來源標示（關帳＝preview、報表檢視＝persisted），避免使用者誤解其中一個是錯的。
- 報表檢視因此可直接重用既有的已產生報表讀取路徑，不需即時預覽的計算依賴。

## Revisit When

出現使用者混淆兩個數字、或報表檢視也需要漂移提示的實際需求時。
