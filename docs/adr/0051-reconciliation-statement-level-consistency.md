# 對帳為報表層級的科目一致性檢查，不做逐帳戶定位

產品規格的 Account Reconciliation 階段（銀行餘額 vs 帳面餘額差異、定位問題帳戶）在資料架構上辦不到：ADR-0007 刻意分離實體帳戶與會計科目，帳面餘額無法逐帳戶計算。決定：對帳的目的定義為**報表層級的科目一致性** — 檢查整體現金、股票等科目的金額在跨報表之間是否一致，不一致時以警示提醒；不嘗試定位到單一帳戶，也不引入帳戶-科目映射。

現金科目的檢查已存在（ADR-0020）：現金流量表期末現金為分錄計算值，資產負債表現金類科目為快照實際值，差額以對帳差異提醒顯示且不自動調平 — ADR-0051 沿用此機制與原則。股票科目（投資部位 vs 股票科目總額）為延伸檢查，比照同一報表層級模式實作。關帳工作流將兩者結果納入階段狀態。取捨：對帳結果是「整體一致 / 有差異」，不是「哪個帳戶錯了」；差異的根因仍由使用者回到原始紀錄追查。

## Considered Options

- 引入帳戶→LedgerCode 映射以計算逐帳戶帳面餘額：違反 ADR-0007 語意分離，且超出規格 out-of-scope，拒絕。
- 對帳定義為快照＋零活動警示組合（先前版本）：仍隱含「找出問題帳戶」的定位目標，與資料架構不符，改為報表層級一致性。
