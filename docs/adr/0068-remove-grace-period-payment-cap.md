# 移除寬限期繳款上限：債務還款單一拆分路徑

**日期：** 2026-09-24
**狀態：** 已實作
**規範來源：** [debt-accounts.md](../debt-accounts.md) §5.5（還款邏輯）

債務還款原本有兩條拆分路徑：寬限期繳款不得高於適用利息（超出即拒絕），寬限期後走正常本金攤還。我們決定移除寬限期上限，統一為單一拆分路徑：實繳 ≤ 應計利息 → 利息全額 + 未覆蓋警告（本金不動）；超出部分記為提前還本（本金攤還，含寬限期內）。原特例分支讓同一個領域計算器有兩種語意，寬限期超繳被拒絕等於禁止使用者提前還本，與「寬限期只豁免本金攤還義務、不豁免利息」的意圖不符。取捨是寬限期內超繳會縮短貸款壽命、改變後續月數；但拆分規則只有一條，分錄由本金是否 > 0 決定，逆向解析不需要寬限期知識。本決定同時把 ADR-0038 的 fingerprint 語意修訂為 v2（加入 `openingBalance` 欄位，綁定計算基準）。
