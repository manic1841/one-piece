# 計畫是可重複使用的假設模板，投影是凍結的計算結果

**日期：** 2026-10-20
**狀態：** 已接受
**規範來源：** [retirement-system.md](../retirement-system.md) §1、§2

v1 把計畫本身當成計算對象：計畫帶著快取 summary、啟用旗標與子集合，時間軸（目前年度）也寫在計畫上。重設計把兩者拆開——計畫只存假設、規則與人生事件，是一份可以重複套用的模板；時間軸、期初餘額與逐年結果只存在於投影，投影一旦建立就唯讀。理由是同一份假設必須能用不同的起算年與期初重跑，而重跑會互相覆蓋快取值；拆開後計畫改了也不會動到已存的結果，刪掉計畫也不會讓舊投影失去意義。

## Consequences

- 計畫不再是「目前生效中的那個」，啟用旗標消失，多份計畫可以並存而不互斥。
- 計畫沒有子集合，投影的子文件才是子集合，兩者的刪除順序與原子性分開對待（ADR-0088）。
- 投影需要自己的名稱與建立時間來在沒有計畫的情況下仍可辨識。
