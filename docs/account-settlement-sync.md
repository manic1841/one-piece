# 帳戶結算金額匯出與匯入 (Account Settlement Sync)

此功能允許使用者透過 CSV 檔案批次匯出與匯入帳戶的每月結算金額（Snapshots）。這對於備份資料、跨年度調整或大量補入歷史資料非常有用。

## 1. CSV 格式規範

匯出與匯入皆使用相同的 CSV 格式。為了確保 Excel 相容性，匯出的檔案已包含 UTF-8 BOM。

### 欄位說明

| 欄位名稱 | 說明 | 範例 |
| :--- | :--- | :--- |
| **日期** | 格式為 `YYYY-MM` | `2024-03` |
| **帳戶名稱** | 必須與系統中現有的帳戶名稱完全一致 | `台幣現金` |
| **幣別** | 帳戶的幣別（匯入時僅供參考，系統會依帳戶設定處理） | `TWD` |
| **結算金額(TWD)** | 該月份結算時的總額（折合台幣） | `50000` |
| **原幣金額** | 該月份結算時的原幣總額（若是台幣帳戶則同上） | `50000` |
| **匯率** | 該月份使用的匯率（台幣帳戶為 1） | `1` |

### 範例內容
```csv
日期,帳戶名稱,幣別,結算金額(TWD),原幣金額,匯率
2024-03,中信台幣,TWD,150000,150000,1
2024-03,玉山美金,USD,31000,1000,31
2024-02,中信台幣,TWD,145000,145000,1
```

## 2. 匯出流程 (Export)

1. 在「帳戶管理 (Account List)」頁面，點擊 **「匯出」** 按鈕。
2. 系統會抓取當前家庭 (Household) 下所有帳戶的所有歷史結算紀錄。
3. 自動下載產生的 CSV 檔案，檔名格式為 `account_settlements_YYYY-MM-DD.csv`。

## 3. 匯入流程 (Import)

1. 在「帳戶管理 (Account List)」頁面，點擊 **「匯入」** 按鈕。
2. 選擇符合上述格式的 CSV 檔案。
3. 系統會逐行解析資料並進行以下校驗：
    - **標題校驗**：檢查是否包含必要的「日期」與「帳戶名稱」欄位。
    - **帳戶名稱校驗**：檢查系統中是否存在該名稱的帳戶。
    - **日期格式校驗**：確保日期符合 `YYYY-MM`。
4. 校驗通過後，系統會呼叫 `recordSnapshot` 寫入或更新該月份的結算金額。
5. 匯入完成後，系統會彈出提示告知成功與失敗的行數。

## 4. 注意事項與錯誤處理

- **重複匯入**：若該帳戶在該月份已存在紀錄，匯入操作會**覆蓋**原有的結算金額。
- **帳戶名稱**：匯入時「帳戶名稱」是唯一的識別基準。若在匯出後於系統中修改了帳戶名稱，則舊的匯出檔在匯入時會找不到對應帳戶。
- **錯誤紀錄**：若匯入過程中發生錯誤（如格式不符、帳戶找不到），系統會記錄該行數與錯誤原因，並在匯入結束後統一顯示。
- **空行跳過**：檔案中的空行會被自動忽略。
